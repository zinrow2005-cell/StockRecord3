# 安心股票簿｜GitHub Pages 直接上傳版

這個資料夾中的檔案已經建置完成，不需要安裝 Node.js，也不需要執行任何指令。

## 上傳方式

1. 解壓縮 ZIP。
2. 進入解壓縮後的資料夾，選取裡面的全部檔案與資料夾。
3. 上傳到 GitHub repository 的最外層，確認 `index.html` 位於最外層，不能再多包一層資料夾。
4. 到 repository 的 **Settings → Pages**。
5. 在 **Build and deployment** 選擇 **Deploy from a branch**。
6. Branch 選擇 `main`，資料夾選擇 `/(root)`，按 **Save**。
7. 等候 GitHub Pages 完成發布，再開啟 GitHub 提供的網址。

## 正確的最外層結構

```text
index.html
404.html
assets/
manifest.webmanifest
service-worker.js
offline.html
icon-192.png
icon-512.png
stock-directory.json
```

只要 GitHub 最外層可以直接看到 `index.html`，GitHub Pages 網址打開後就會直接進入「安心股票簿」，不會再顯示 README 說明頁。

## 最近交易日官方收盤價（v1.6.1）

- APP 開啟後會在背景抓取目前持股的最近一個已完成交易日收盤價。
- 上市股票使用臺灣證券交易所（TWSE）官方 OpenAPI；上櫃股票使用證券櫃檯買賣中心（TPEx）官方 OpenAPI。
- 週末、休市日會保留最近交易日資料；官方來源暫時失敗時，不會清除上一次成功保存的價格。
- 「總覽」會自動計算最近收盤市值、未實現損益與庫存報酬率；「持股」卡片會顯示每檔最近收盤價與損益。
- 「損益與期間統計」仍保留手動修正股價功能，並新增「重新抓取官方收盤價」按鈕。

## 月／季／年／自由區間統計（v1.6.0）

- 到「損益與報酬中心」可切換 **月、季、年、自由區間**。
- 月／季／年可用左右箭頭切換上一期、下一期，也能直接指定月份、季度或年份。
- 自由區間可直接指定開始日與結束日。
- 期間統計包含：買進投入、賣出淨收、已實現損益、現金股利、現金減資退回、交易費稅、交易筆數、區間截止持股成本與各股票明細。
- 若選到包含未來日期的期間，已發生統計只計算到今天，避免把未來預計股利誤算成已實現收入。
- 歷史區間不會拿「目前股價」回推當時的未實現損益；要計算歷史總報酬，未來可再加入每日／每月歷史收盤價快照。

## 資料保存方式

- 股票資料保存在目前手機或瀏覽器內，不會上傳到 GitHub。
- 同一個 GitHub Pages 網址，在不同手機開啟時不會自動共用資料。
- 換手機、清除瀏覽器資料或重新安裝前，請先到「設定 → 資料備份與匯出」下載 JSON 完整備份。
- 新手機第一次開啟後，再用「匯入 JSON 備份」還原。

## 內建股票與電子下單優惠

- APP 已內建參考 Excel 中的 46,725 筆股票代號與名稱；常用股票、ETF、ETN、TDR 等使用快速索引，輸入完整代號後會立即帶入名稱，不會連線至證交所、櫃買中心或其他外部股票網站。
- 券商設定會先選內建券商，再選 Excel 整理的電子下單優惠方案；共 74 個方案，也可手動輸入折數與最低手續費。
- 電子下單只輸入優惠折數，系統會自動換算實際費率並套用買進、賣出與費用試算。
- 沒有固定公開折扣的券商會標示「優惠待確認」，不會假設所有帳戶使用同一折扣。
- 優惠資格、活動期限與月退方式可能變動，請以券商契約或成交對帳單為準。
